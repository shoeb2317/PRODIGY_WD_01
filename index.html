Project Overview

How It Meets All Requirements

Designed with clean HTML5 semantic architecture, CSS3 modern variables, and modular ES6 JavaScript.

Scroll Color Shift

When scrolling past the threshold, JavaScript triggers the .scrolled class, modifying background tint, backdrop blur, elevation shadow, and padding dynamically.

Hover Interactions

Each navigation link highlights with a smooth background pill, subtle scale transform, and vibrant color shift on hover with keyboard accessibility.

Smart Active Scrollspy

Uses modern IntersectionObserver to detect which section of the page is currently in view and automatically updates the active menu link.

Theme Switcher

Seamlessly toggle between a sleek cyberpunk dark mode and a crisp clean light mode, with preferences saved to localStorage.
